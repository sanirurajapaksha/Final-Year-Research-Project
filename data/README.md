# Data

| Folder | What goes here |
|---|---|
| `fixtures/` | Small inputs for tests and demos: hand-written or recorded telemetry, cluster snapshots (`kubectl get -o json`), sample commands. Say in the file whether it is hand-written or recorded, and from where. |
| `corpora/` | Labelled datasets, e.g. M3's command corpus. Write the labelling rule down (in the corpus folder) **before** running a module on it. |

Never put secrets, kubeconfigs or real personal data here.
